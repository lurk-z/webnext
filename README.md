# FlavOriz Next.js

This project is a Next.js version of the provided recipe website design. It includes the main navigation pages, recipe filtering, recipe detail pages, and working form submissions.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Test forms

- Newsletter submissions are saved to `data/subscribers.json`.
- Contact form messages are saved to `data/contact-messages.json`.

The `data` folder and JSON files are created after the first successful submit.

## Production commands

```bash
npm run build
npm run start
```
